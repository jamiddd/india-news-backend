Download the APK

How to install

  1. Tap Download the APK above on an Android phone.
  2. Open the downloaded file. Android will ask whether to allow installs from this source — this prompt is normal for any app installed outside the Play Store.
  3. Allow it, then tap Install.

Android 8 and above ask for that permission per app, so allowing it here does not change any other setting on the device. It can be turned off again afterwards under Settings → Apps → Special access → Install unknown apps.

Signing in

The app can be used without an account. Signing in (with Google, or an email and password) is needed only for features tied to a profile — saved stories, notification scheduling, and making a donation.

About donations in the app

The app is free and every feature is available at no cost. The only payment it accepts is an optional donation towards running costs, which unlocks nothing — no features, no premium status, and no change of any kind inside the app.
